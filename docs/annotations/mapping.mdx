# @Mapping

Controls field-level mapping for a single target field. Apply multiple `@Mapping` annotations to the same method to configure multiple fields.

## Signature

```dart
const Mapping({
  required String target,
  String? source,
  bool ignore = false,
  bool forceNonNull = false,
  MappingCallable? callable,
  String? qualifiedBy,
  String? defaultValue,
  String? constant,
  String? expression,
  String? conditionExpression,
})
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `target` | `String` | — (required) | Name of the target field to configure. A dotted name (`'address.street'`) configures a property of a nested target object, or a nested key of a target map. |
| `source` | `String?` | `null` | Name of the source field or of a method parameter. Use dot notation for nested access (`'address.city'`). Comma-separated names (`'first,last'`) pass several values to a `callable` or to a mapper method. Defaults to the target field name if omitted. |
| `ignore` | `bool` | `false` | When `true`, the target field is skipped entirely. The target class must handle the missing value (e.g., with a default or nullable type). |
| `forceNonNull` | `bool` | `false` | When `true`, force-unwraps a nullable source field. Use when you know the source will not be null at runtime. Not allowed on a comma-separated `source` without `callable`. |
| `callable` | `MappingCallable?` | `null` | A function reference that computes the target field value. The function receives the source parameter(s) and returns the target field value. |
| `qualifiedBy` | `String?` | `null` | Selects the mapper method that converts the source(s), as `'methodName'` or `'MapperClass.methodName'`. The signature is still checked. Cannot combine with `callable`, `expression`, `constant`, or `ignore`. |
| `defaultValue` | `String?` | `null` | A Dart expression string used as the value when the source field is `null`. Examples: `"'unknown'"`, `"0"`, `"false"`. |
| `constant` | `String?` | `null` | A constant Dart expression emitted as the target field value regardless of the source. Examples: `"'v1'"`, `"42"`. |
| `expression` | `String?` | `null` | A raw Dart expression emitted verbatim. Access source parameters by their declared names. Cannot combine with `source`, `defaultValue`, `constant`, or `callable`. |
| `conditionExpression` | `String?` | `null` | A boolean Dart expression. When `true`, the field maps normally. When `false`, falls back to `defaultValue` (or `null` if nullable). Cannot combine with `constant` or `callable`. |

## Field Renaming

Map a source field with a different name to the target field:

```dart
@Mapping(target: 'name', source: 'firstName')
User toUser(UserDto dto);
```

## Ignoring a Field

Skip a target field — the target class must handle the missing value:

```dart
@Mapping(target: 'internalId', ignore: true)
User toUser(UserDto dto);
```

## Force Non-Null

When the source is nullable but you know it won't be `null` at runtime:

```dart
@Mapping(target: 'email', source: 'email', forceNonNull: true)
User toUser(UserDto dto);
```

## Default Value

Provide a fallback value when the source field is `null`:

```dart
@Mapping(target: 'role', source: 'role', defaultValue: "'user'")
User toUser(UserDto dto);
```

The `defaultValue` must be a string representation of a valid Dart expression.

## Constant Value

Always use a fixed value regardless of the source:

```dart
@Mapping(target: 'version', constant: "'1.0'")
UserDto toDto(User user);
```

## Callable

Delegate the field computation to a function:

```dart
String _formatName(UserDto dto) => '${dto.firstName} ${dto.lastName}';

@Mapper()
abstract class UserMapper {
  @Mapping(target: 'name', callable: _formatName)
  User toUser(UserDto dto);
}
```

See [Callable Mapping guide](/guides/callable-mapping) for multi-argument callables.

## Several Sources and Mapper Methods

A comma-separated `source` combines several values. With `callable` they are the arguments of the function. Without `callable`, the generator looks for a mapper method (in `uses` first, then in the mapper itself) whose parameters accept them, in order:

```dart
@Mapper(uses: {OrderingMapper})
abstract class SettingsMapper {
  @Mapping(source: 'orderField,orderDescending', target: 'ordering')
  Settings from(SettingsDTO dto);
}
```

Generated: `ordering: orderingMapper.from(dto.orderField, dto.orderDescending)`. If more than one method fits, choose with `qualifiedBy`:

```dart
@Mapping(
  source: 'orderField,orderDescending',
  target: 'ordering',
  qualifiedBy: 'OrderingMapper.fromFlat',
)
Settings from(SettingsDTO dto);
```

`qualifiedBy` also picks one converter for a single source when several have the same signature. See the [Mapper Methods guide](/guides/mapper-methods).

## Expression

Emit a raw Dart expression directly:

```dart
@Mapping(target: 'fullName', expression: 'dto.firstName + " " + dto.lastName')
User toUser(UserDto dto);
```

For multi-source methods, use parameter names as declared:

```dart
@Mapping(target: 'displayName', expression: 'user.name + " (" + profile.handle + ")"')
UserView combine(User user, Profile profile);
```

## Conditional Expression

Map conditionally — falls back to `defaultValue` when the condition is false:

```dart
@Mapping(
  target: 'name',
  source: 'name',
  conditionExpression: 'dto.name.isNotEmpty',
  defaultValue: "'Anonymous'",
)
User toUser(UserDto dto);
```

## Combination Rules

These combinations are **not allowed** and produce a build-time error:

| Combination | Reason |
|-------------|--------|
| `constant` + `source` | Constant ignores the source |
| `constant` + `defaultValue` | Constant is always set — default is unreachable |
| `constant` + `callable` | Both compute the value — ambiguous |
| `defaultValue` + `callable` | Both compute the value — ambiguous |
| `expression` + `source` | Expression renders the source access verbatim |
| `expression` + `constant` | Expression renders a value verbatim |
| `expression` + `defaultValue` | Expression renders a value verbatim |
| `expression` + `callable` | Both compute the value — ambiguous |
| `conditionExpression` + `constant` | Condition needs source access |
| `conditionExpression` + `callable` | Both control the output flow |
| `qualifiedBy` + `callable` | Both select how the value is computed |
| `qualifiedBy` + `expression` | Expression renders a value verbatim |
| `qualifiedBy` + `constant` | Constant is always set |
| `qualifiedBy` + `ignore` | The field is skipped |
| `forceNonNull` + comma-separated `source` without `callable` | The mapper method receives the nullable values itself |

Valid combinations with a comma-separated `source` resolved by a mapper method:

| Combination | Behavior |
|-------------|----------|
| `qualifiedBy` | picks the method by name |
| `defaultValue` | applied with `??` to the method result |
| `conditionExpression` | wraps the call |
| dotted `target` | the call builds the nested property |

## With Maps

When a method maps to or from a `Map`, each map key plays the role of a field:

| Attribute | Behavior |
|-----------|----------|
| `target` / `source` | The map key. `source: 'id', target: 'uid'` writes key `uid`; on the way back, `source: 'uid', target: 'id'` reads it. |
| `ignore` | Omits the key from the produced map. |
| `defaultValue` | Fallback for a missing key when reading (`map['k'] as String? ?? 'x'`). |
| `forceNonNull` | A no-op for `dynamic` / `Object?` values, generates `!` for `Map<String, T?>`. |
| Dot notation | Source paths walk nested maps; a dotted `target` builds nested maps (class to Map) or nested objects (class to class, Map to class). |

See the [Map Mapping guide](/guides/map-mapping).
